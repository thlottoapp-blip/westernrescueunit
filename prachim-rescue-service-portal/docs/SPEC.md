# สมาคมประจิมสารคาม พุทธศาสตร์สงเคราะห์ (หน่วยกู้ภัยประจิม)
## System Specifications & Architectural Blueprint (SPEC.md)

### 1. บทนำและวัตถุประสงค์ (System Overview)
ระบบศูนย์บริการและบริหารจัดการข้อมูลการปฏิบัติการ **หน่วยกู้ภัยประจิม (สมาคมประจิมสารคาม พุทธศาสตร์สงเคราะห์)** 
สำนักงานตั้งอยู่ ณ ถนนแจ้งสนิท ตำบลบรบือ อำเภอบรบือ จังหวัดมหาสารคาม 44130 
ระบบถูกออกแบบเพื่อเป็นศูนย์กลางข้อมูลการกู้ชีพ-กู้ภัย 24 ชั่วโมง (Hotline: 061-119-3342 / 1669) สำหรับประชาชนในพื้นที่อำเภอบรบือ, วาปีปทุม, นาดูน และพื้นที่ใกล้เคียงในจังหวัดมหาสารคาม พร้อมระบบศูนย์ควบคุมสั่งการและบริหารจัดการเนื้อหาสำหรับเจ้าหน้าที่ (Admin Content & Dispatch CMS)

### 2. กลุ่มผู้ใช้งานและสิทธิ์การเข้าถึง (Actors & Roles)

| บทบาท (Role) | สิทธิ์การเข้าถึง (Permissions) | ขอบเขตการทำงาน (Scope) |
|---|---|---|
| **Public / ประชาชนทั่วไป (Citizen)** | Read Only (ข่าวสาร/ผลงาน/เกณฑ์ค่าบริการ) + Create (แจ้งเหตุด่วน/ขอความช่วยเหลือ) | ดูข้อมูลภารกิจ, ข่าวสาร, เกณฑ์ค่าบริการ, หมายเลขฉุกเฉิน, ทำการแจ้งเหตุฉุกเฉินพร้อมพิกัด GPS/รูปถ่าย, ตรวจสอบสถานะการออกเหตุ |
| **Emergency Dispatcher / เจ้าหน้าที่สั่งการ** | Read/Update Emergency Requests + Create Mission Logs | รับเรื่องแจ้งเหตุฉุกเฉิน, จัดสรรกำลังพลและรถพยาบาล/อุปกรณ์พิเศษ, อัปเดตสถานะการออกเหตุ (รับแจ้ง -> กำลังเดินทาง -> ถึงที่เกิดเหตุ -> นำส่ง รพ.) |
| **System Administrator / ผู้ดูแลระบบ** | Full CRUD on all modules + Category Management + Security Settings | จัดการข่าวสาร, ผลงานเด่น, หมวดหมู่ภารกิจ, ทำเนียบเจ้าหน้าที่/อาสาสมัคร, สถานะยานพาหนะและอุปกรณ์ตัด-ถ่าง/ชุดประดาน้ำ, เปลี่ยนรหัสผ่านและค่าระบบ |

### 3. บริการหลักและเกณฑ์ค่าบริการ (Service Matrix & Cost Transparency)

1. **ระบบบริการการแพทย์ฉุกเฉิน (EMS) และอุบัติเหตุทางถนน 24 ชม.:** **ฟรี 100%** (สนับสนุนโดย สพฉ. และ รพ.บรบือ)
2. **งานบรรเทาสาธารณภัยและช่วยเหลือชุมชน (จับงู/สัตว์มีพิษ, รถเสีย, ดับเพลิงเบื้องต้น):** **ฟรี 100%** (จิตอาสาเพื่อสังคม)
3. **ชุดปฏิบัติการกู้ภัยทางน้ำและประดาน้ำค้นหาผู้สูญหาย:** **ฟรี 100%** (สนับสนุนภารกิจค้นหาเพื่อมนุษยธรรม)
4. **การส่งผู้ป่วยติดเตียง / ร่างผู้วายชนม์ยากไร้กลับภูมิลำเนาข้ามจังหวัด:** เคสสงเคราะห์ยากไร้ **ฟรี** / เคสทั่วไปอาจมีค่าใช้จ่ายเฉพาะ **"ค่าน้ำมันตามระยะทางจริง"**
5. **บริการรถยก / รถลากจูงเมื่อเกิดอุบัติเหตุ:** หน่วยกู้ภัยประสานงานเครือข่ายรถยกเอกชนให้ **ผู้ใช้บริการชำระค่าบริการตามจริงของบริษัทรถยก**

### 4. สถาปัตยกรรมทางเทคนิค (Tech Stack & Architecture)
- **Frontend Framework:** Next.js 15+ (App Router), React 19, TypeScript
- **Styling & Theme:** Tailwind CSS, Emergency Red/Crimson (#DC2626, #991B1B) & Professional Deep Slate/Navy (#0B1120, #1E293B)
- **Iconography:** Lucide Icons (Strictly no emojis)
- **Typography:** Google Fonts (Prompt & Sarabun for Thai formal readability)
- **State Management & Persistence:** Real-time Dispatch Store with LocalStorage fallback & Database synchronization
- **Security:** Session PIN/Password Authentication for Administration Portal
