# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/7ec793c0-906d-4539-83f7-913ac50c5e4b

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

**หมายเหตุ:** แอปนี้ไม่ต้องใช้ API Key แบบเสียเงินใด ๆ
- แผนที่ใช้ Google Maps Embed (ฟรี ไม่ต้องใช้ key)
- ระบุตำแหน่ง GPS ใช้ Geolocation ในตัวเบราว์เซอร์ (ฟรี)
